# Evidence Summary

이 프로젝트는 네이버 채널의 판매성과, 광고성과, 고객현황, 공식 프로모션 성과를 통합해 월간 Sell-out 운영 의사결정을 지원하기 위해 구축한 대시보드입니다.

## 핵심 증빙

- 원본 Excel 수정 없이 대시보드용 데이터마트 JSON 생성
- 공식 프로모션 성과와 전체 일매출 기준 분리
- 구매완료 기준 광고 ROAS 관리
- 프로모션, CRM, LIVE 이벤트 마커 기반 매출 흐름 분석
- Google Apps Script 배포용 번들 생성 구조 설계
- 민감 데이터 공개 범위 점검 후 포트폴리오용 공개 저장소 분리

## 직무 연결성

이 프로젝트는 온라인 채널 운영과 전략 직무에서 요구되는 다음 역량을 보여줍니다.

- Sell-out KPI 실행관리
- D2C 및 마켓플레이스 운영 데이터 해석
- 프로모션 활용도와 광고 효율 분석
- 플랫폼 운영 개선 요구사항 정의
- 데이터 기반 월간 성과 리뷰 체계화

## 강조 포인트

이 저장소는 코딩 역량 자체보다 운영 설계 역량을 보여주기 위한 자료입니다. 핵심은 어떤 데이터를 볼지 정의하고, 어떤 기준으로 지표를 분리하며, 어떤 운영 액션으로 연결되게 만들었는지입니다.
