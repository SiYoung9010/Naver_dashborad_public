# Public Release Policy

이 문서는 원본 프로젝트를 포트폴리오용 공개 저장소로 전환할 때 적용한 공개 범위 기준입니다.

## 공개 가능

- 프로젝트 목적과 비즈니스 문제 정의
- 대시보드 섹션 구성
- 데이터 파이프라인 구조 설명
- 민감정보가 제거된 예시 데이터 스키마
- 실행 방법과 의존성
- 채용 포트폴리오용 증빙 요약

## 공개 제외

- 상품 ID 및 상품명
- 기준가, 할인가, 최대혜택가, 쿠폰 조건
- 공식 프로모션 PDF 원본
- 원본 Excel 파일과 실제 파일명
- 회사 내부 운영 메모
- 실제 매출, 광고비, 전환수, 고객 데이터
- 실제 데이터가 내장된 Google Apps Script 배포 결과물

## 공개 방식

- 원본 저장소는 private 상태로 유지합니다.
- 공개 저장소에는 민감정보를 제거한 설명 문서와 예시 데이터만 포함합니다.
- 노션 포트폴리오에는 대시보드 캡처와 해석 중심으로 정리하고, GitHub는 기술적 증빙 링크로 보조 활용합니다.

## 데이터 신뢰성 원칙

- 원본 데이터를 임의 수정하지 않습니다.
- 집계 기준이 다른 지표를 단순 합산하지 않습니다.
- 공식 성과자료에 없는 지표는 임의 생성하지 않습니다.
- 외부 공유 전 데이터 식별 가능성을 점검합니다.
